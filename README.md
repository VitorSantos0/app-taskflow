
# TaskFlow

Aplicativo de Gerenciamento de Rotina Diária.

## Objetivo
Desenvolver um aplicativo móvel intuitivo que permita ao usuário organizar suas tarefas diárias através de diferentes perspectivas temporais (mensal, semanal e diária). O foco principal é a objetividade, garantindo que a inserção e consulta de afazeres sejam feitas com o mínimo de cliques possível.

## Justificativa
A fragmentação da atenção é um dos maiores desafios da atualidade. Muitos aplicativos de agenda pecam pelo excesso de funcionalidades ("bloatware"), o que afasta o usuário que busca apenas uma organização rápida. Este projeto justifica-se pela necessidade de uma ferramenta que combine:

Visão Macro: Planejamento a longo prazo (Aba Mês).
Visão Meso: Organização da rotina imediata (Aba Semana).
Visão Micro: Execução e foco no "agora" (Aba Dia).

Tecnicamente, o projeto serve para aplicar conceitos de State Management (para manter as tarefas sincronizadas entre as abas) e Design de Interface Responsiva em dispositivos móveis.
